# Quick Setup Guide

## Repository URL (Copy this!)

```
https://raw.githubusercontent.com/zetlaska/mangayomi-extensions/main/index.json
```

## Setup Steps (iOS/iPhone)

1. Open **Mangayomi** app
2. Go to **Browse** → **Settings** (⚙️)
3. Tap **Extension Repositories**
4. Tap **+** button
5. **Paste the URL above**
6. Save and return to Browse
7. Tap **Filter Manga extensions**
8. Enable **Asura Scans**
9. Done! Start reading 🎉
